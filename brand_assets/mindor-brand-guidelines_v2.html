Brand Voice & Tone

  • Sharp. Direct. Confident.
  • Identity-driven, operator-coded
  • Slightly intense, never goofy
  • Credible — shows its work
  • Intimate to the buyer's pain
Mindor Is Not
  • Bro-science hype
  • Yoga-wellness soft
  • Generic "clean energy" noise
  • Lab-coat stiff
  • Hustle-culture cringe

Design Do's & Don'ts

Do
Use CSS tokens — never hardcode hex values
Layer radial gradients for surface depth
Animate only transform and opacity
Barlow Condensed for display, DM Sans for body
Sprint Blue (#4A6BD4) as the primary interactive accent
Signal Purple (#9B7FE0) for accent badges and interactive highlights
Don't
Use transition-all — it causes layout thrash
Mix more than 2 font families on one surface
Use position: sticky on content in unequal grids
Default Tailwind palette — never generic pastel-on-white
Flat box shadows with no color tint
Generic AI fonts (Inter, Roboto, Arial, system-ui)
